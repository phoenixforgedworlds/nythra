# Nythra

**Nythra** is a single-player Pathfinder 2e campaign for Foundry Virtual Tabletop, published with ECB.

## Compatibility

- **Foundry VTT:** 14.368
- **Pathfinder 2e system:** 8.5.1
- **Campaign version:** 0.1.0

## Installation

1. Download the latest Nythra ZIP from this repository's **Releases** page.
2. Extract the archive into your Foundry data folder at `Data/modules/`.
3. Make sure the resulting folder is `Data/modules/nythra/` and contains `module.json`.
4. Launch Foundry, open a Pathfinder 2e world, and enable **Nythra** from **Manage Modules**.

## Campaign Saves

Nythra uses the player character Actor as the portable campaign save. Keep/export that Actor if you want to preserve a playthrough outside the current Foundry world.

## About

Nythra is built from an ongoing Pathfinder 2e campaign and adapted into a single-player experience using ECB (the PF2e Single-Player Campaign Builder).
